# psutil: Monitor CPU/RAM during experiments

# ============================================================================
# PERFORMANCE TIPS
# ============================================================================

# For faster data loading:
#   - Use Parquet instead of CSV (10-20× faster)
#   - Use pyarrow engine: pd.read_parquet('data.parquet', engine='pyarrow')

# For faster plotting:
#   - Use matplotlib 'Agg' backend for batch generation
#   - Disable interactive mode: plt.ioff()

# For memory efficiency:
#   - Load data in chunks: pd.read_csv('data.csv', chunksize=10000)
#   - Use categorical dtypes: df['controller'] = df['controller'].astype('category')
